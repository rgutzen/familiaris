# Conventions — Router

<!-- LAYER 3 · DIRECTIVE · Agents propose changes, never make them -->

| Writing or deciding… | Read |
|---|---|
| how to talk to the user — tone, disagreement, ask vs decide, verification, response shape | `collaboration.md` |
| prose that lands in this system — leaves, docs, reports, commit messages | `voice.md` |
| code, or what a docstring must contain | `code-style.md` |

Standing instructions to an agent. Not knowledge leaves: not scored, not
decayed, not agent-writable — which is why they sit outside `knowledge/`.

- **A docstring is governed by both** `voice.md` (how its sentences read) and
  `code-style.md` (what it must contain). Neither restates the other.
- **Not here:** text published *under the user's name* is `../user/user-voice.md`
  — a profile of a person, not house style. Rules that are *enforced* rather
  than stated are `../boundaries/`.
