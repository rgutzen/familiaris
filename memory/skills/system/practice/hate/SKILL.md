## When NOT to use this

- **The design is still open** — `grilling` interviews the branches out; there
  is no load-bearing assumption yet to attack.
- **You want the idea validated by evidence** — `spike` runs the experiment.
  This names the cheapest one and stops.
- **The plan is empirical and the worry is independence** — `mandela` owns the
  leakage taxonomy. Do not restate it here: a second copy is the drift that
  [[knowledge-vs-skills]] forbids.
- **You want the plan improved.** Attacking and improving are different
  reflexes and merging them produces a rewrite wearing a critique's clothes.

## Local notes

- **The output is one root plus one nail, never a list.** The compression is
  the value: a checklist of ten objections gets triaged into nothing.
- **User-invoked on purpose, upstream and here.** A demolition reflex always in
  reach biases the agent toward demolition — including on work the user has
  already decided. `/hate` means the user asked for it.
- **Its empirical axes are where the local judgement lies.** Leakage belongs to
  `mandela`; power and family-wise α belong to a statistician, not to an
  objection the agent invents. When the nail is statistical, say so and stop.
- **It pairs with `prism` rather than duplicating it:** `prism` spreads across
  heterogeneous lenses and returns the open question; `hate` collapses to the
  objection that would kill the thing. Run both only when the artifact is
  expensive.
